# Coffee Sales Analysis

## Project Overview

This project analyzes coffee shop sales data using Microsoft Excel to understand sales performance, customer preferences, and purchasing patterns.

The analysis transforms raw transaction data into meaningful insights that can support business decision-making and improve sales performance.

## Business Questions

- Which products generate the highest sales?
- What are the peak sales hours?
- Which payment methods are most preferred?
- Which products are most frequently ordered?
- How does sales performance vary throughout the day?

## Tools & Techniques

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Dashboard Design

## Key Insights

- Sales performance varies throughout the day, with noticeable peaks during specific hours.
- Americano with Milk is among the most frequently ordered products.
- Latte generates higher revenue compared with some products despite differences in order volume.
- Cash is one of the most preferred payment methods.
- Identifying peak sales periods can help optimize staffing and inventory planning.

## Dashboard

The project includes an interactive Excel dashboard that presents key sales metrics, trends, product performance, and customer preferences in a clear and easy-to-understand format.
